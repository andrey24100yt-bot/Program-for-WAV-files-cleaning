# Program-for-WAV-files-cleaning
Программа для отчистки звуковых файлов из датасетов. Проверено на 04_Ресторан, rar архивы результатов и датасета прилогаются.
Создано группой МТ-202 Челгу: Васильевым Андреем, Моториным Михаилом, Ветиным Константином, Тагильцевой Дарьей, Вороновым Арсением и Филиповским Виталием.

Скрипт:
1. Проверяет все WAV в dataset/ и сохраняет inventory.csv.
2. Проверяет пары clean/noisy по идентификаторам sp01...sp30.
3. Для трёх выбранных фраз строит waveform, FFT и спектрограммы.
4. Измеряет SNR исходных записей и характеристики спектра шума.
5. Применяет один частотный фильтр: полосовой фильтр Баттерворта.
6. Сохраняет 12 обработанных WAV и таблицу экспериментов (24 строки).

Перед запуском:
Пропишите в терминал:

    python -m pip install -r requirements.txt

1) Сначала скачайте данные: python download_dataset.py
2) Затем запустите обработку: python main.py
